# Dataset Information

## Dataset Used

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains approximately 100,000 orders from the Brazilian e-commerce platform Olist, including information about orders, customers, sellers, products, payments, reviews, and delivery.

## Source

Kaggle: Brazilian E-Commerce Public Dataset by Olist

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Purpose

The dataset is used for data collection, cleaning, preprocessing, exploratory analysis, predictive modeling, clustering, and logistics analysis.

## Note

The original dataset is not stored directly in this GitHub repository. It can be downloaded from the official Kaggle source above.
